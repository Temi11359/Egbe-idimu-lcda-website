# Egbe-Idimu LCDA Website

A modern, responsive, black-and-yellow government council information website built with plain HTML, CSS and JavaScript.

## Run in Visual Studio Code

### Option 1 — simplest
1. Extract the ZIP.
2. Open the extracted `egbe-idimu-lcda-website` folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click `index.html` and choose **Open with Live Server** if you have the Live Server extension.
5. Or simply double-click `index.html` to open it directly in a browser.

### Option 2 — VS Code terminal
No package installation is required. The website is static.

You can also run:
- Windows: `start index.html`
- macOS: `open index.html`
- Linux: `xdg-open index.html`

## Files

- `index.html` — complete webpage structure/content
- `styles.css` — responsive black/yellow visual design
- `script.js` — department search, category filters, department detail modals and mobile navigation
- `assets/egbe-idimu-logo.jpg` — the supplied council logo
- `.vscode/launch.json` — optional VS Code browser launch configuration

## Department information

The department directory is structured around Lagos LCDA administrative functions and includes:
Administration & Human Resources; Finance & Accounts; Works & Infrastructure; Primary Healthcare; Education & Library Services; Environmental Health Services; Women Affairs & Poverty Alleviation; Agriculture & Social Services; Planning, Budget, Research & Statistics; Legal; Public Affairs; Procurement; ICT; Internal Audit; and Tourism/Cultural Affairs.

Some responsibilities are written as general service descriptions rather than claims about a specific current officer or internal workflow. Confirm current office contacts, procedures and departmental naming before publishing as an official council website.

## Sources used for factual structure

- Lagos State Independent Electoral Commission (LASIEC): current LGA/LCDA and ward listing.
- Public information associated with Egbe-Idimu LCDA: council location, administrative roles and recent departmental references.
- Lagos LCDA examples such as Ojokoro LCDA's administrative structure were used to cross-check common department/unit functions.

This project is a website concept/template and should be reviewed and approved by the council before being represented as an official government website.
